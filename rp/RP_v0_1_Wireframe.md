# PhoenixRecover 原型（v0.1 低保真线框）

> 来源：`PRD_PhoenixRecover.md`（P1–P5 核心流程）  
> 目标：先把 **主链路**（选位置 → 扫描 → 结果/预览 → 选择恢复目标 → 完成）跑通，形态对标 EaseUS。

---

## 1. 信息架构 / 路由

```text
P1 位置选择（RecoveryLocationPage）
  └── Start Scan → P2 扫描中（RecoveryScanPage: Scanning）
                  ├── Stop / Pause / Resume
                  └── View Results（可选）→ P3 结果/预览（同一页的结果态）

P3 结果/预览（RecoveryScanPage: Results）
  └── Recover Selected / Recover All → P4 选择恢复目标（RecoveryTargetPage）

P4 选择恢复目标（RecoveryTargetPage）
  └── Start Recover → P5 完成（RecoveryCompletePage）
```

---

## 2. P1 位置选择（RecoveryLocationPage）

### 2.1 布局线框

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 左侧导航                                                                       │
│  数据恢复                                                                      │
│   - 磁盘                                                                        │
│   - SD 卡                                                                       │
│   - 更多恢复工具                                                                 │
│  高级功能                                                                       │
│   - 文件恢复                                                                    │
│   - 丢失分区恢复                                                                 │
├──────────────────────────────────────────────────────────────────────────────┤
│  选择要查找丢失数据的位置                                                       │
│                                                                              │
│  本地磁盘（N）                                                                  │
│  [ 磁盘卡片 C:  卷标/FS  容量条 ] [ D: ... ] [ E: ... ]  (横向滚动)             │
│                                                                              │
│  指定位置                                                                       │
│  [ 回收站 ]   [ 桌面 ]   [ 选择文件夹 ]   [ 外接设备(后续) ]                    │
│                                                                              │
│  扫描模式                                                                       │
│  [ 快速扫描 ]   [ 深度扫描 ]   [ RAW 扫描 ]                                     │
│                                                                              │
│                                   (找不到理想数据？)   [ 查找丢失数据 ]         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 交互要点
- **目标互斥选择**：本地磁盘卡片、回收站/桌面/选择文件夹等只能选一个。
- **扫描模式互斥选择**：Quick/Deep/Raw 三选一，默认 Quick。
- **选择文件夹**：弹目录选择对话框，选中后将路径作为扫描目标（P0）。
- **Start Scan**：点击后进入扫描页，发射信号：

```cpp
signals:
  void requestStartScan(const QString& locationOption,
                        const QString& diskLetter,
                        int scanMode);
```

```text
┌──────────────────────────────────────────────────────────────────────────────┐

│ 已发现：12,345  已扫描：120GB/500GB  用时：00:03:21  进度：34%                 │
├──────────────────────────────────────────────────────────────────────────────┤
│ [筛选]  [搜索文件或文件夹.................................................]   │
├───────────────┬──────────────────────────────────────────┬───────────────────┤
│ 左侧导航       │ 中间文件表格（实时追加）                 │ 右侧详情/预览      │
│  Tab: 路径/类型 │  [ ] 名称 | 大小 | 类型 | 日期 | 概率   │  预览区域          │
│  Path Tree     │  [ ] ...                                 │  属性列表          │
│  Type Tree     │                                          │                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 进度条 ███████████████████████████▏                                           │
│ 状态：正在扫描…                                                               │
│                                                                              │
│                               [暂停] [停止] [查看结果] [恢复全部(可禁用)]       │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 交互要点（P0）
- **暂停**：暂停扫描，UI 仍可浏览已发现文件（实现上需要 Worker 支持 pause）。
- **停止**：终止扫描但保留已发现结果，进入“结果态”（P3）。
- **查看结果**：边扫边切换到“结果态”（不中断扫描，P1）。
- **实时追加**：文件以 batch 方式追加，避免 UI 卡顿。
- **搜索/筛选**：至少支持“文件名搜索 + 类型筛选”（P0）。

### 4.1 布局线框（与 P2 共用框架，不同状态）

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [新建扫描]  结果：共发现 90,412 项  总大小 7.0GB  耗时 00:12:03               │
├──────────────────────────────────────────────────────────────────────────────┤
│ [筛选]  [搜索............................................................]   │
├───────────────┬──────────────────────────────────────────┬───────────────────┤
│ Tab: 路径/类型 │ [☑] 名称 | 大小 | 类型 | 日期 | 概率      │ 预览 / 详情        │
│ Path/Type Tree │ [☐] ...                                 │                   │
│                │                                          │                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 已选：123 项 (456MB)                                                          │
│                                             [导出列表] [保存会话] [恢复所选]    │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 4.2 交互要点
- **多选勾选**：每行复选框；表头全选/反选（P0）。
- **恢复概率列**：High/Medium/Low 颜色标签（P0）。
- **预览**：
  - 图片：右侧缩略图（P0）
  - 文本：前 1KB 预览（P1）
  - 其他：图标占位（P0）
- **导出列表/保存会话/加载会话**：P1（先定义入口按钮和信号）。

## 5. P4 恢复目标选择（RecoveryTargetPage）

### 5.1 布局线框

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [返回结果]  选择恢复位置                                                       │
├──────────────────────────────────────────────────────────────────────────────┤
│ 目标路径： [ ..................................................... ] [选择]  │
│                                                                              │
│ 提示：不要将文件恢复到源盘（例如 C:）以防覆盖。                                │
│                                                                              │
│ 待恢复：123 个文件，总计 456MB                                                │
│ 预览：a.jpg, b.docx, c.mp4, ... 等 123 个                                     │
│                                                                              │
│                                                         [开始恢复]            │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 交互要点（P0）
- 选择目录（必须可写）
- 安全校验：目标路径不可与源盘同卷；空间不足提示
- 发射信号：

```cpp
signals:
  void requestStartRecover(const QString& targetPath,
                           const QVector<quint64>& fileIds);
```
