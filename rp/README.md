# 可点击 HTML 原型（rp）

## 打开方式
- 直接双击打开 `index.html`（不需要联网）
- 或在浏览器地址栏输入本地路径：`...\PhoenixRecover\rp\index.html`

## 页面

### 数据恢复流程
- `index.html`：入口与说明
- `p1_location.html`：P1 位置选择（扫描目标，自动多阶段扫描）
- `p2_scanning.html`：P2 扫描中（带阶段指示器：元数据解析 → 深度扫描 → 签名雕刻，完成自动跳转）
- `p3_results.html`：P3 结果&预览（含可恢复性标注、搜索筛选面板，点击"恢复全部"进入 P4）
- `p4_target.html`：P4 选择恢复目标（点击"开始恢复"进入 P5）
- `p5_complete.html`：P5 恢复完成（可"新建恢复"回到 P1）

### 工具页面
- `p6_repair.html`：P6 文件修复（支持 ZIP/MP4/JPEG/PNG，拖拽上传 → 分析 → 修复结果下载）
- `p7_imaging.html`：P7 磁盘镜像（选择源磁盘 → 设置保存路径 → 进度/速度/剩余时间 → 完成/错误状态）
- `p8_smart.html`：P8 磁盘健康监测（S.M.A.R.T. 数据，磁盘卡片 + 健康评分 + 关键属性表格）

## 交互说明
- 扫描模式/目标会保存在浏览器 `localStorage` 中，便于页面间传递（仅用于原型演示）。
- P2 扫描页会自动切换阶段指示（元数据解析 → 深度扫描 → 签名雕刻）。
- P6 文件修复支持拖拽上传和点击浏览两种方式，带模拟分析动画。
- P7 磁盘镜像带模拟进度动画，可切换完成/错误状态查看。
- P8 磁盘健康点击不同磁盘卡片可查看对应的 S.M.A.R.T. 属性表。

## 样式与脚本
- `styles.css`：全局样式（接近 EaseUS 的浅色风格）
- `app.js`：简化交互（跳转/进度动画/状态保存/新页面路由）
