## P1：恢复位置选择页（RecoveryLocationPage）

### 目标
- 选择扫描目标（回收站/桌面/选择文件夹/本地磁盘）
- 选择扫描模式（快速/深度/RAW）
- 点击开始扫描进入 P2

### 线框

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 标题：选择要查找丢失数据的位置                                                │
├──────────────────────────────────────────────────────────────────────────────┤
│ [本地磁盘（N）]                                                               │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐        (横向滚动)         │
│ │ Local Disk C │ │ Local Disk D │ │ Local Disk E │  ...                       │
│ │ NTFS  120/256│ │ exFAT  10/64 │ │ NTFS  80/512 │                            │
│ │ [容量进度条] │ │ [容量进度条] │ │ [容量进度条] │                            │
│ └──────────────┘ └──────────────┘ └──────────────┘                            │
│                                                                              │
│ 扫描模式                                                                      │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐                            │
│ │ 快速扫描 (○) │ │ 深度扫描 ( ) │ │ RAW 扫描  ( ) │                            │
│ └──────────────┘ └──────────────┘ └──────────────┘                            │
│                                                                              │
│ 指定位置                                                                      │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐                            │
│ │ 回收站  ( )  │ │ 桌面    ( )  │ │ 选择文件夹( ) │                            │
│ └──────────────┘ └──────────────┘ └──────────────┘                            │
│                                                                              │
│ [找不到理想数据？]                                      [开始扫描/查找丢失数据] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 关键交互（P0）
- 未选择目标时：开始扫描按钮禁用
- 选择磁盘/位置 + 扫描模式后：按钮可用
- 选择文件夹：弹出目录选择对话框
- 点击开始扫描：发射 `requestStartScan(locationOption, diskLetter, scanMode)`

## P2：扫描进度页（RecoveryScanPage — 扫描中）

### 目标
- 显示扫描进度（目标/模式/已发现数量/容量/耗时/百分比）
- 支持暂停/停止（P0）
- 可边扫描边浏览已发现文件（路径/类型视图）

### 线框

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [返回]  扫描目标：本地磁盘(C:)  | 模式：快速扫描  | 已发现：12,345             │
│        已扫描：80.3GB / 256GB  | 用时：00:08:22   | 进度：31%                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ [筛选▼]  [搜索：输入文件名/扩展名...]                              [查看结果] │
├───────────────┬───────────────────────────────────────┬──────────────────────┤
│ 左侧：视图Tab  │ 中间：文件表格（支持边扫边追加）       │ 右侧：详情/预览        │
│ [路径] [类型]  │ ┌───────────────────────────────────┐ │ ┌──────────────────┐ │
│ 目录树/类型树   │ │[ ] 名称 | 大小 | 类型 | 日期 | 概率 │ │ │ 预览区/图标占位   │ │
│                │ │...                                   │ │ │ 名称/大小/路径... │ │
│                │ └───────────────────────────────────┘ │ └──────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ 进度条：██████████████░░░░░░░░░░░░░░                                         │
│ 状态文本：正在扫描…（实时追加中）                                            │
│ [暂停] [停止]                                             [恢复选中] [恢复全部]│
└──────────────────────────────────────────────────────────────────────────────┘
```

### 关键交互（P0）
- **暂停**：扫描暂停，进度停住；可恢复
- **停止**：终止扫描，但保留已发现结果并进入“结果浏览态”（或直接提示已取消）
- **查看结果**：切到结果浏览（不中断扫描）

## P4：恢复目标选择页（RecoveryTargetPage）

### 目标
- 选择恢复目录（必须不同于源盘）
- 检查磁盘空间/可写权限
- 点击开始恢复进入 P5

### 线框

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 标题：选择恢复位置                                                            │
├──────────────────────────────────────────────────────────────────────────────┤
│ 待恢复摘要：12 个文件 | 1.2GB                                                 │
│                                                                              │
│ 目标路径： [ C:\Users\...\Recovered\            ] [选择文件夹...]              │
│ 提示：恢复位置不能与源盘相同（避免覆盖）。                                   │
│                                                                              │
│ 校验区：                                                                     │
│ - 源盘覆盖检测：通过/失败（失败则阻止继续）                                  │
│ - 剩余空间：xx GB（不足则提示）                                              │
│ - 可写权限：通过/失败                                                        │
│                                                                              │
│ [返回]                                                     [开始恢复]         │
└──────────────────────────────────────────────────────────────────────────────┘
```
