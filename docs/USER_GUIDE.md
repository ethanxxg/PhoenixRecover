# PhoenixRecover 用户指南

PhoenixRecover 是一款 Windows 桌面数据恢复工具，支持从硬盘、U 盘、SD 卡等存储设备中恢复误删除或丢失的文件。

---

## 系统要求

| 项目 | 最低要求 |
|------|----------|
| **操作系统** | Windows 10 (64-bit) 或更高版本 |
| **内存** | 4 GB RAM（推荐 8 GB 以上） |
| **磁盘空间** | 500 MB（程序安装）+ 足够的恢复目标空间 |
| **运行时** | 无需额外运行时，所有依赖已打包 |

> Linux 和 macOS 支持处于实验阶段，当前仅 Windows 平台提供完整功能。

---

## 安装说明

1. 从发布页面下载最新的安装包或便携版压缩包。
2. **安装版**：运行安装程序，按提示完成安装。
3. **便携版**：解压到任意目录，运行 `PhoenixRecover.exe` 即可。

> **重要提示**：请勿将程序安装到需要恢复数据的磁盘上，以免覆盖待恢复的文件。

---

## 快速开始：三步恢复

### 第 1 步：选择扫描位置

启动 PhoenixRecover 后，在主界面选择需要恢复数据的磁盘或分区。程序会自动列出当前系统中的所有可用磁盘。

### 第 2 步：等待扫描完成

点击「开始扫描」，程序将自动执行三阶段扫描：

1. **元数据解析**：从文件系统结构中恢复文件信息
2. **深度扫描**：搜索残留的目录项和 MFT 记录
3. **签名雕刻**：通过文件头特征匹配发现更多文件

扫描过程中会实时显示进度和已发现的文件数量。如需中断，可随时点击「取消」。

### 第 3 步：选择并恢复文件

扫描完成后，浏览发现的文件列表：

1. 通过左侧目录树或类型树定位文件。
2. 使用搜索框按文件名筛选。
3. 勾选要恢复的文件。
4. 点击「恢复」按钮，选择目标保存目录。
5. 等待恢复完成，查看恢复报告。

> **注意**：请将文件恢复到与源磁盘**不同**的磁盘，程序会自动检测并阻止同卷写入。

## 功能说明

### 扫描

PhoenixRecover 采用智能三阶段流水线，自动选择最优扫描策略，无需用户手动切换模式：

- **阶段 1 — 元数据解析**：解析 NTFS / FAT / exFAT / ext4 文件系统元数据，恢复完整目录结构和文件属性。
- **阶段 2 — 深度扫描**：扫描磁盘残留的 MFT 条目和 FAT 目录项，发现已被文件系统标记删除的文件。
- **阶段 3 — 签名雕刻**：使用 300+ 内建文件签名在原始扇区数据中匹配文件头，适用于文件系统严重损坏的场景。

### 恢复

- 支持批量恢复（全选或手动勾选）。
- 可选保留原始目录结构。
- 恢复过程显示实时进度，支持随时取消。
- 恢复完成后展示统计摘要和详细明细，支持导出报告。

### 预览

在扫描结果中选中文件即可在右侧预览面板查看：

- 图片文件显示缩略图预览。
- 视频文件提取关键帧缩略图（需系统已安装 FFmpeg 或使用 Windows Shell 解码器）。

### 文件修复

对恢复出的损坏文件，可尝试自动修复：

- **ZIP 修复**：扫描本地文件头，重建中心目录与 EOCD。
- **MP4 修复**：重定位 moov atom 或通过 FFmpeg remux 修复播放问题。

> 修复始终保留原文件不动，输出到新文件。

### 磁盘镜像

将物理磁盘或分区完整导出为镜像文件（raw image），适用于：

- 在磁盘状态恶化前创建备份副本。
- 对镜像文件离线执行恢复扫描，避免反复读取故障磁盘。

### S.M.A.R.T. 健康监测

读取磁盘的 S.M.A.R.T. 属性，展示关键健康指标，帮助判断磁盘是否存在潜在硬件故障。

### 会话保存与恢复

- 扫描完成后自动保存会话。
- 下次启动时可加载上次的扫描结果，无需重新扫描。

### 自定义文件签名

通过 JSON 文件添加自定义文件签名，扩展签名雕刻阶段的识别能力。格式说明详见 `docs/SIGNATURE_FORMAT.md`。
